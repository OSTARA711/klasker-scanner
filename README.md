# Klasker Scanner

Klasker Scanner is the website evidence extraction and evaluation engine
for Klasker AITA (Artificial Intelligence Trade Analysis).

The scanner analyses websites for HTTP, security, metadata, structured
data and AI-agent discoverability signals.

## Current version

The initial version is based on Klasker Scanner v0.1.1.

## Architecture

The scanner is intended to run as part of the Klasker backend on multiple
active-active Serv00 nodes.
